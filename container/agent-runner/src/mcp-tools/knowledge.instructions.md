## Shared Knowledge

Use `knowledge_search` before answering questions that depend on Alteryx or project-specific
facts. Ground the response in the returned text and include each useful `source_uri` or
`relative_path` as a citation. State clearly when the index does not contain enough evidence.

Use `knowledge_ingest` after the user adds or changes source material and needs it immediately.
Use `knowledge_write_output` only for requested durable artifacts; choose a descriptive path
beneath `40 Generated` and prefer Markdown.
